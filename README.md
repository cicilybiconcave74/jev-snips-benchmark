## 📊 Understanding Results

Results are presented as counts, scores, and example-level outcomes. A higher score means more requests were handled correctly. A lower score means more requests need attention. Do not judge a run from one example alone. Look at the overall pattern and then inspect the examples that failed.

Intent classification results show whether the main purpose of a request was recognized. Slot filling results show whether important details were captured. Token classification results show how individual words or phrases were labeled. Few-shot and zero-shot results show how the setup performs when examples are limited or absent.

Use the failed examples as a learning list. Group similar failures together. Look for repeated words, phrasing patterns, or missing details. These patterns often reveal the best next step, such as adding clearer examples, adjusting labels, or testing a different benchmark area.

## 🔍 Evaluation Areas

The application covers several natural language understanding evaluation areas. Intent classification focuses on what the user wants. Slot filling focuses on the details needed to act on that intent. Token classification focuses on labeling parts of the request. Few-shot evaluation tests performance when only a small number of examples are available. Zero-shot evaluation tests performance when no task-specific examples are provided.

These areas work together. A request can have the right intent but a missing slot. A token can be labeled correctly while the overall intent is wrong. Reviewing more than one area gives a fuller picture of understanding quality.
